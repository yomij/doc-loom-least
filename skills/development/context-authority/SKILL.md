# Context and Authority

## Establish Context

Read `references/shared-protocol.md` for authority, case identity, risk, and
resume rules. Reuse the router's workspace snapshot or obtain one.

For authority, workflow or agent policy, public-contract, or high-risk work,
start with the active constitution, authority index, and applicable approved
governance. Read relevant implementation, evidence, and current case artifacts.
Treat historical and derived material as supporting context.

Resolve an existing case or propose a slug to `docloom-workflow`; do not create
a case or write its plan.

## Return a Verdict

Summarize material sources, constraints, conflicts, and risk in conversation.
Use `templates/context-authority-brief.md` only when conflict, an explicit
request, continuity, or independently needed context requires a saved brief.

| Verdict | Meaning |
|---|---|
| `proceed_to_plan` | Sufficient context; no blocking conflict. |
| `proceed_to_plan_with_risk` | A non-blocking gap remains. |
| `needs_user_decision` | A material fact or choice cannot be resolved. |
| `needs_case_selection` | The case cannot be selected reliably. |
| `run_setup_doc_governance` | Governance must be established first. |
| `blocked_by_authority_conflict` | Current authority or evidence has a material conflict. |

Block planning on material conflicts. Reversible internal drift may proceed
with recorded risk; consequential evidence gaps remain blocking.
